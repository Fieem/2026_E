# SCARA J1 关节控制器

该固件通过 FDCAN1 控制 SCARA 底座的无刷电机。主控不使用 IMU，也不运行
外部位置 PID；关节目标角度直接发送给 QD4310 的角度模式，由电机控制器
根据自身角度反馈完成位置闭环。

## 电机与 CAN 配置

- 电机节点 ID：`0x01`
- 控制指令 CAN ID：`0x401`
- 电机反馈 CAN ID：`0x501`
- CAN 模式：经典 CAN，速率 1 Mbit/s
- 反馈数据：QD4310 八字节状态帧

机械限位、旋转方向和零点偏移在 `App/scara_j1_config.h` 中配置。连接机械臂
之前，必须先校准这些参数。

系统复位后电机默认处于失能状态。J1 运行期间，如果 CAN 反馈或上位机心跳
超时，控制器将进入故障状态并立即使电机失能。

## 树莓派串口协议

USART1 波特率为 921600，数据帧采用小端字节序：

| 字段 | 长度 | 说明 |
| --- | ---: | --- |
| 帧头 | 1 字节 | 固定为 `0xA5` |
| 负载长度 | 1 字节 | 该字段之后的数据字节数 |
| 命令 ID | 2 字节 | 见下方命令表 |
| 标志位 | 2 字节 | 保留字段，发送时填零 |
| 数据 | 0～8 个 float32 | 命令参数 |

| 命令 ID | 数据 | 功能 |
| --- | --- | --- |
| `0x0001` | 无 | 心跳 |
| `0x0101` | 无 | 以零转速使能 J1 |
| `0x0102` | 无 | 使 J1 失能 |
| `0x0103` | 角度，单位为弧度 | 设置 J1 目标位置 |
| `0x0104` | 转速，单位为 rpm | 手动转速模式 |
| `0x0105` | 无 | 停止并失能 |
| `0x0106` | 无 | CAN 反馈在线时清除故障 |

J1 处于运行状态时，树莓派应至少每 500 ms 发送一次心跳。当前上位机看门狗
超时时间为 1500 ms。

USART10 预留给第二块主控，用于控制两个步进电机、Z 轴舵机和电磁铁。
当前固件暂未处理 USART10 接收到的数据。

## 编译与烧录

```powershell
cmake --fresh --preset Debug
cmake --build --preset Debug
cmake --build --preset Debug --target flash
```

编译完成后，会在 `build/Debug` 目录中生成 `Gimbal1.elf`、`Gimbal1.hex` 和
`Gimbal1.bin`。执行烧录目标时，需要通过 SWD 接口连接 ST-LINK。
